常见问题

还有疑问？

Hermes Agent 是 Nous Research 开源的 AI Agent 框架，运行在命令行。Hermes Panel 是它的可视化控制面板，提供 Web 界面来管理对话、工作区、工具集成等功能。Panel 通过 Hermes Agent 的 API（默认 :8642）与之通信。
Web 版（浏览器 / npx）提供 11 项基础功能：对话、会话管理、仪表盘、统计、健康监控、通知中心、用户管理、基础设置、功能探测、偏好管理和 Draft 跨端桥接。Desktop 版额外解锁 13 项高级功能：工作区、定时任务、记忆管理、文件管理、MCP 工具、技能、插件、开发者工具、密钥管理、模型供应商、备份、诊断、沙箱和网关。
不会。Hermes Panel 完全本地部署，所有对话数据、工作区文件、配置信息都存储在你的设备上。没有遥测，不上传任何业务数据。
Windows、macOS、Linux 全平台支持。提供 Tauri 桌面客户端、NPX 命令行和 VS Code 扩展三种使用方式。
