📝 评估要点

  • 方案 A（毛玻璃）：日常用最自然，跟 macOS Big Sur+ 风格一致。Tauri 桌面应用里能开 window.transparent = true 真正透到桌面壁纸
  • 方案 B（玻璃拟态）：视觉冲击最强，发布截图好看，但长时间用眼睛累
  • 方案 C（Tokyo Night）：开发者最爱，配色克制，几乎不依赖背景

💡 实施后 Settings → 外观 → 配色模式将出现第 4 个选项 半透明，与亮/暗/跟随系统并列。 会沿用当前已选主题色（11 种），所以 strokes/buttons 颜色不变，只是背景层和卡片层变透明。
