# Code Of Conduct

Hermes Panel follows the Contributor Covenant Code of Conduct, version 2.1.

## Our Pledge

We pledge to make participation in this project a respectful and welcoming
experience for everyone.

## Expected Behavior

- Be kind and constructive.
- Assume good intent while still being precise about technical risk.
- Keep discussions focused on the code, documentation, product behavior, and
  user impact.
- Respect maintainers' time by providing reproduction steps and context.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Publishing private information without permission.
- Repeatedly derailing technical discussions.
- Any behavior that makes the project hostile to contributors or users.

## Enforcement

Maintainers may remove comments, close issues, or restrict participation when
behavior violates this code of conduct.
